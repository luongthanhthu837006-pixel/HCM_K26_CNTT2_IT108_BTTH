Phần1: Kiến trúc Hệ điều hành.
+ Đây là hoạt động chức năng quản lý tiến trình và quản lý tài nguyên của hệ điều hành. Word, Chrome, VS Code và Portal chạy cùng lúc nhờ hệ điều hành phân chia CPU, RAM và quản lý các tiến trình riêng, giúp chúng hoạt động ổn định, hạn chế xung đột.
+ Khi double-click file, thao tác với Shell trước. Shell nhận thao tác và yêu cầu hệ điều hành mở file bằng ứng dụng phù hợp. Kernel quản lý phần cứng, bộ nhớ và tiến trình nên người dùng thường không làm việc trực tiếp với nó.

Phần6: Đuôi file và file ẩn.
   + Đây có thể là cạm bẫy giả đuôi file. File hiển thị de-thi-dap-an.pdf nhưng tên thật có thể là:
de-thi-dap-an.pdf.exe

Cách kiểm tra trước khi mở:
- Mở File Explorer.
- Chọn View -> Show -> File name extensions trên Windows 11.
- Kiểm tra lại tên đầy đủ và phần đuôi file.
- Nếu file đáng ngờ được tải từ link lạ trên Zalo, không mở file, hãy xóa hoặc nhờ người có chuyên môn kiểm tra.
